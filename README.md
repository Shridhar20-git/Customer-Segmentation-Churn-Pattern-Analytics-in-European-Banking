# Customer-Segmentation-Churn-Pattern-Analytics-in-European-Banking

An interactive data analytics dashboard developed to analyze customer
segmentation, churn patterns and high-value customer risk in the
European banking sector.

## 📊 Project Overview

This project analyzes customer demographic, account and activity data
to identify patterns associated with customer churn.

The dashboard provides interactive visualizations and business insights
that can help understand customer attrition and identify high-value
customers affected by churn.

## 🚀 Key Features

- Overall customer churn analysis
- Geography-wise churn analysis
- Age-band churn analysis
- Active vs inactive customer churn comparison
- Customer balance segmentation
- High-value customer identification
- Revenue exposure analysis
- Interactive dashboard filters
- High-value customer explorer
- Filtered dataset download
- Dark and light dashboard themes

## 🛠️ Technologies Used

- Python
- Pandas
- Plotly
- Streamlit
- Data Visualization
- Exploratory Data Analysis
